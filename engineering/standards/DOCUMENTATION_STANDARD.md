# CellCount Documentation Standard

Every new enterprise module must contain:

- `README.md`: purpose, installation and usage.
- `SPEC.md`: functional requirements and acceptance criteria.
- `ARCHITECTURE.md`: dependencies, boundaries and design decisions.
- `CHANGELOG.md`: version history.
- `contracts/`: public schemas or contract descriptions.
- `examples/`: executable or copyable examples.

Documentation must describe actual implemented behavior.
