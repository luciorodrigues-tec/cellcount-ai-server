INF-SCALE-001.2H-C — Capacity Envelope & Scale Recommendation Certification

- capacityHeadroom
- estimatedDrainMinutes
- currentWorkers / recommendedWorkers
- queuePressure / workerUtilization / waitingPerWorker / oldestWaitingAgeMs

Adds recommendation hysteresis to the read-only operational snapshot. No automatic worker mutation is introduced.
