# CI-002A — Morphologic Knowledge Foundation

A versioned and specimen-aware morphology knowledge domain has been added.

The foundation separates:
- entities;
- criteria;
- evidence strength;
- references;
- validation;
- registry and search;
- catalog loading.

No clinical diagnosis engine is introduced in this sprint. CI-002A only
establishes the immutable, testable infrastructure required by later knowledge
libraries and reasoning engines.
