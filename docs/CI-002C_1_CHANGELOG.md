# CI-002C.1 — Criteria Definition Engine

The 15-cell knowledge library now has formal, immutable and validated criteria
definitions.

Positive morphology criteria are separated into required and supportive rules.
Negative, exclusion and limitation criteria remain distinct. All rules reference
validated feature keys and include weights, thresholds and source criterion IDs.

This sprint defines criteria only. Feature matching, scoring and candidate
ranking remain intentionally deferred to CI-002C.2 and later.
